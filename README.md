# Redux Setup

Starter React exercise for Redux store integration with header and counter components.

## Project structure

- `src/redux/store.js`
- `src/components/Counter.jsx`
- `src/components/Header.jsx`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/redux-setup.git
cd redux-setup
npm install
npm run dev
```

Open the development URL displayed in the terminal.
